# Archives des prototypes de boutique

Ce dossier contient 15 maquettes HTML statiques conservées comme références
visuelles. Elles ne font pas partie du parcours actif et aucune page publique
du site ne pointe vers elles.

Le parcours fonctionnel actuel utilise les pages PHP situées à la racine :

- `pricing.html` pour le catalogue ;
- `shop-cart.php` pour le panier ;
- `shop-checkout.php` pour la validation ;
- `shop-account-login.php` et `shop-account-register.php` pour le compte ;
- `shop-account-orders.php` pour l'historique des commandes ;
- `payment-redirect.php`, `pending.php`, `success.php` et `cancel.php` pour les
  états de commande et de paiement.

Ne créez pas de nouveaux liens publics vers les fichiers HTML de ce dossier.
Lorsqu'une fonctionnalité utile d'une maquette doit être reprise, elle doit
être adaptée dans le parcours PHP actif.
